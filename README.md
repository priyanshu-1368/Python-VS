# Python Beginner Scripts

This repository contains two simple Python scripts demonstrating basic console input/output, data types, variable handling, and structured text display.

---

## File Overview

### 1. Interactive Biodata Program (`Biodata.py`)
An interactive command-line application that collects user details and displays their formatted biodata alongside data type descriptions[cite: 1].
* **Key Features:**
  * Prompts for name, age, height, and favorite number[cite: 1].
  * Displays variable types for each input[cite: 1].
  * Calculates and outputs the estimated birth year[cite: 1].

### 2. Institute Information Script (`first.py`)
A structured text output script dedicated to Red & White Multimedia Education[cite: 2].
* **Key Features:**
  * Displays the organization's Mission and Vision statements[cite: 2].
  * Outlines core values: Integrity, Student-Centered Focus, and Innovation[cite: 2].
